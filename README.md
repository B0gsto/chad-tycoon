# Tycoon design reference screenshots

This private repository contains 21 screenshots captured while exploring the Roblox experience **Zombie Tycoon** (game ID `87907239343172`), plus a contact sheet for quick review.

The images document the tycoon layout, collection and deposit loop, chest interaction, and Shop, Index, and Ranking interfaces. They are retained as visual reference while developing an original Chad/Aura themed tycoon.

## Contents

- `Screenshot *.png` — individual captured views
- `contact-sheet.jpg` — thumbnail overview of the image set
